Zustand 状态管理 ​

一、Zustand 核心概念 ​

1. 什么是 Zustand？ ​

Zustand 是一个轻量级的 React 状态管理库，以其简洁的 API 和出色的性能著称。

核心特点：

  • 极简 API，无需 Provider 包装
  • 支持中间件（如 devtools、persist）
  • 自动优化重渲染
  • 支持 TypeScript
  • 极小的包体积（约 1KB）

2. 与其他状态管理库对比 ​

库包体积API 复杂度Provider学习曲线
Zustand~1KB低不需要低
Redux~14KB高需要高
Context API内置中需要中
MobX~13KB中不需要中

npm install zustand

二、基础用法 ​

1. 创建 Store ​

javascript
// src/store/index.js
import { create } from 'zustand';

const useStore = create((set, get) => ({
  // 状态
  count: 0,
  name: 'Zustand',
  
  // Action
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 }),
  
  // 带参数的 Action
  setName: (name) => set({ name }),
  
  // 依赖其他状态的 Action
  doubleCount: () => set((state) => ({ count: state.count * 2 })),
  
  // 使用 get 获取当前状态
  getCount: () => get().count,
}));

export default useStore;

2. 在组件中使用 ​

jsx
// components/Counter.js
import useStore from '../store';

function Counter() {
  // 订阅特定状态
  const count = useStore((state) => state.count);
  const name = useStore((state) => state.name);
  
  // 获取 Action
  const { increment, decrement, reset, setName } = useStore();
  
  return (
    <div>
      <h2>{name}</h2>
      <p>Count: {count}</p>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
      <button onClick={reset}>Reset</button>
      <input 
        type="text" 
        value={name} 
        onChange={(e) => setName(e.target.value)} 
      />
    </div>
  );
}

export default Counter;

三、进阶用法 ​

1. 异步操作 ​

javascript
// src/store/index.js
import { create } from 'zustand';

const useStore = create((set) => ({
  users: [],
  loading: false,
  error: null,
  
  fetchUsers: async () => {
    set({ loading: true, error: null });
    
    try {
      const response = await fetch('/api/users');
      const users = await response.json();
      set({ users, loading: false });
    } catch (error) {
      set({ error: error.message, loading: false });
    }
  },
  
  addUser: async (user) => {
    const response = await fetch('/api/users', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(user)
    });
    const newUser = await response.json();
    set((state) => ({ users: [...state.users, newUser] }));
  }
}));

3. 选择器优化 ​

jsx
// ❌ 不好的做法：每次渲染都会创建新函数
const user = useStore((state) => ({ name: state.name, age: state.age }));

// ✅ 好的做法：使用稳定的选择器
const selectUser = (state) => ({ name: state.name, age: state.age });
const user = useStore(selectUser);

// ✅ 使用 shallow 比较
import { shallow } from 'zustand/shallow';

const user = useStore(
  (state) => ({ name: state.name, age: state.age }),
  shallow
);

// ✅ 获取多个独立状态
const [name, age] = useStore(
  (state) => [state.name, state.age],
  shallow
);

五、Zustand 面试题 ​

问题 1：Zustand 的核心优势是什么？ ​

答案：

  1. 极简 API：无需 Provider，直接使用
  2. 性能优秀：只订阅需要的状态，避免不必要的重渲染
  3. 轻量级：包体积约 1KB
  4. 中间件支持：支持 devtools、persist 等中间件
  5. TypeScript 友好：完整的类型支持

问题 2：Zustand 和 Redux 的区别？ ​

答案：

维度ZustandRedux
包体积~1KB~14KB
API 复杂度低高
Provider不需要需要
中间件内置支持需要额外安装
学习曲线低高
适用场景中小型应用大型复杂应用

问题 3：如何在 Zustand 中处理异步操作？ ​

答案： 直接在 Action 中使用 async/await：

javascript
const useStore = create((set) => ({
  data: null,
  loading: false,
  
  fetchData: async () => {
    set({ loading: true });
    const response = await fetch('/api/data');
    const data = await response.json();
    set({ data, loading: false });
  },
}));

问题 7：Zustand 的 set 和 get 函数有什么作用？ ​

答案：

  • set：用于更新状态，可以接收对象或函数
  • get：用于获取当前状态
javascript
const useStore = create((set, get) => ({
  count: 0,
  
  // 使用 set 更新状态
  increment: () => set((state) => ({ count: state.count + 1 })),
  
  // 使用 get 获取当前状态
  getCount: () => get().count,
  
  // 使用 get 依赖其他状态
  double: () => set({ count: get().count * 2 }),
}));

六、完整 Demo：购物车应用 ​

javascript
// src/store/cartStore.js
import { create } from 'zustand';
import { devtools, persist } from 'zustand/middleware';

interface CartItem {
  id: string;
  name: string;
  price: number;
  quantity: number;
}

interface CartStore {
  items: CartItem[];
  addItem: (item: Omit<CartItem, 'quantity'>) => void;
  removeItem: (id: string) => void;
  updateQuantity: (id: string, quantity: number) => void;
  clearCart: () => void;
  total: number;
}

const useCartStore = create<CartStore>()(
  devtools(
    persist(
      (set, get) => ({
        items: [],
        
        addItem: (item) => {
          const existingItem = get().items.find((i) => i.id === item.id);
          
          if (existingItem) {
            set((state) => ({
              items: state.items.map((i) =>
                i.id === item.id
                  ? { ...i, quantity: i.quantity + 1 }
                  : i
              ),
            }));
          } else {
            set((state) => ({
              items: [...state.items, { ...item, quantity: 1 }],
            }));
          }
        },
        
        removeItem: (id) => {
          set((state) => ({
            items: state.items.filter((i) => i.id !== id),
          }));
        },
        
        updateQuantity: (id, quantity) => {
          if (quantity <= 0) {
            get().removeItem(id);
            return;
          }
          
          set((state) => ({
            items: state.items.map((i) =>
              i.id === id ? { ...i, quantity } : i
            ),
          }));
        },
        
        clearCart: () => set({ items: [] }),
        
        total: 0, // 计算属性将在选择器中处理
      }),
      {
        name: 'cart-storage',
      }
    )
  )
);

// 计算总价
export const useCartTotal = () =>
  useCartStore((state) =>
    state.items.reduce((sum, item) => sum + item.price * item.quantity, 0)
  );

export default useCartStore;

// components/Cart.js
import useCartStore, { useCartTotal } from '../store/cartStore';

function Cart() {
  const items = useCartStore((state) => state.items);
  const { updateQuantity, removeItem, clearCart } = useCartStore();
  const total = useCartTotal();

  if (items.length === 0) {
    return <div>Cart is empty</div>;
  }

  return (
    <div>
      <h2>Shopping Cart</h2>
      
      <ul>
        {items.map((item) => (
          <li key={item.id}>
            <h3>{item.name}</h3>
            <p>Price: ${item.price}</p>
            <input
              type="number"
              min="0"
              value={item.quantity}
              onChange={(e) =>
                updateQuantity(item.id, parseInt(e.target.value) || 0)
              }
            />
            <button onClick={() => removeItem(item.id)}>Remove</button>
          </li>
        ))}
      </ul>
      
      <p>Total: ${total.toFixed(2)}</p>
      <button onClick={clearCart}>Clear Cart</button>
    </div>
  );
}

export default Cart;

八、总结 ​

Zustand 适用场景：

  • 中小型 React 应用
  • 需要简单状态管理的项目
  • 追求性能和简洁性的团队

学习路径：

  1. 理解核心 API（create、set、get）
  2. 学习中间件使用（devtools、persist）
  3. 掌握选择器优化技巧
  4. 学习切片组织方式

与其他库配合：

  • 可以与 React Query 配合处理服务端状态
  • 可以与 React Router 配合处理路由状态
  • 可以与 TypeScript 无缝集成

Zustand 以其极简的 API 和出色的性能，成为 React 状态管理的热门选择，特别适合那些不需要 Redux 复杂性的项目。
