React Router 详解 ​

一、React Router 核心概念 ​

1. 什么是 React Router？ ​

React Router 是 React 应用中实现路由功能的标准库，它允许你在单页应用中实现页面之间的导航。

核心特点：

  • 声明式路由定义
  • 嵌套路由支持
  • 动态路由参数
  • 导航守卫
  • 代码分割支持

2. React Router v6 新特性 ​

React Router v6 带来了许多重要改进：

特性v5v6
路由定义Switch + RouteRoutes + Route
嵌套路由手动嵌套自动嵌套
路由匹配顺序匹配最佳匹配
Linkto 属性to 属性（支持对象）
导航useHistoryuseNavigate
路由参数useParamsuseParams
重定向RedirectNavigate

三、进阶用法 ​

1. 编程式导航 ​

jsx
import { useNavigate } from 'react-router-dom';

function Login() {
  const navigate = useNavigate();

  const handleLogin = () => {
    // 登录逻辑...
    
    // 导航到首页
    navigate('/');
    
    // 导航并替换历史记录
    navigate('/', { replace: true });
    
    // 导航到上一页
    navigate(-1);
    
    // 传递状态
    navigate('/dashboard', { state: { userId: '123' } });
  };

  return <button onClick={handleLogin}>Login</button>;
}

3. 查询参数 ​

jsx
import { useSearchParams } from 'react-router-dom';

function SearchResults() {
  const [searchParams, setSearchParams] = useSearchParams();
  
  // 获取查询参数
  const query = searchParams.get('q');
  const page = searchParams.get('page');
  
  // 设置查询参数
  const handlePageChange = (newPage) => {
    setSearchParams({ q: query, page: newPage });
  };
  
  return (
    <div>
      <p>Search: {query}</p>
      <p>Page: {page}</p>
      <button onClick={() => handlePageChange(2)}>Go to page 2</button>
    </div>
  );
}

// components/ProtectedRoute.js
import { Navigate, useLocation } from 'react-router-dom';

function ProtectedRoute({ children }) {
  const isAuthenticated = checkAuth(); // 检查用户是否登录

  return children;
}

六、React Router 面试题 ​

问题 1：React Router v6 相比 v5 有哪些重大变化？ ​

答案：

  1. Switch 被 Routes 取代：Routes 提供更精确的匹配算法
  2. 嵌套路由简化：使用 Outlet 自动渲染子路由
  3. useHistory 被 useNavigate 取代：提供更简洁的 API
  4. Redirect 被 Navigate 取代
  5. 路由匹配优化：从顺序匹配改为最佳匹配
  6. 相对路径：支持相对路径导航

问题 2：BrowserRouter 和 HashRouter 的区别？ ​

答案：

维度BrowserRouterHashRouter
URL 形式/about/#/about
服务器配置需要配置服务器无需服务器配置
SEO友好不友好
历史记录HTML5 history APIwindow.location.hash
适用场景生产环境静态站点、开发环境

// 使用

问题 5：什么是 Outlet 组件？ ​

答案：Outlet 是 React Router v6 中用于渲染嵌套路由的组件。当父路由匹配时，Outlet 会渲染对应的子路由组件。

jsx
function Parent() {
  return (
    <div>
      <h1>Parent</h1>
      <Outlet /> {/* 子路由内容 */}
    </div>
  );

问题 10：React Router 的工作原理是什么？ ​

答案：

  1. URL 监听：使用 HTML5 history API 或 hash 监听 URL 变化

jsx
// src/App.js
import { BrowserRouter, Routes, Route, NavLink } from 'react-router-dom';
import { lazy, Suspense } from 'react';

// 懒加载组件
const Home = lazy(() => import('./pages/Home'));
const Posts = lazy(() => import('./pages/Posts'));
const PostDetail = lazy(() => import('./pages/PostDetail'));
const CreatePost = lazy(() => import('./pages/CreatePost'));
const NotFound = lazy(() => import('./pages/NotFound'));

function App() {
  return (
    <BrowserRouter>
      <nav>
        <NavLink 
          to="/" 
          className={({ isActive }) => isActive ? 'active' : ''}
        >
          Home
        </NavLink>
        <NavLink 
          to="/posts" 
          className={({ isActive }) => isActive ? 'active' : ''}
        >
          Posts
        </NavLink>
        <NavLink 
          to="/posts/new" 
          className={({ isActive }) => isActive ? 'active' : ''}
        >
          Create Post
        </NavLink>
      </nav>
      
      <Suspense fallback={<div>Loading...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/posts" element={<Posts />} />
          <Route path="/posts/:id" element={<PostDetail />} />
          <Route path="/posts/new" element={<CreatePost />} />
          <Route path="*" element={<NotFound />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}

export default App;

// pages/PostDetail.js
import { useParams, useNavigate, useLocation } from 'react-router-dom';

const posts = {
  '1': { title: 'React Router Guide', content: '...full content...' },
  '2': { title: 'Redux Best Practices', content: '...full content...' },
  '3': { title: 'TypeScript Tips', content: '...full content...' }
};

function PostDetail() {
  const { id } = useParams();
  const navigate = useNavigate();
  const location = useLocation();
  const post = posts[id];
  
  if (!post) {
    return <div>Post not found</div>;
  }
  
  return (
    <div>
      <button onClick={() => navigate(-1)}>Back</button>
      <h1>{post.title}</h1>
      <p>{post.content}</p>
      <p>From: {location.state?.from || 'unknown'}</p>
    </div>
  );
}

export default PostDetail;

八、总结 ​

React Router v6 的核心优势：

  1. 更简洁的 API
  2. 更好的嵌套路由支持
  3. 代码分割友好
  4. 类型安全（TypeScript 支持）

学习重点：

  1. 路由配置（Routes、Route）
  2. 导航（Link、useNavigate）
  3. 参数处理（useParams、useSearchParams）
  4. 嵌套路由（Outlet）
  5. 路由守卫（Navigate）

最佳实践：

  1. 使用懒加载减少首屏加载时间
  2. 集中管理路由配置
  3. 使用路由守卫保护敏感路由
  4. 合理使用 useEffect 处理参数变化
