一、Ant Design 基础 ​

1. 什么是 Ant Design？ ​

Ant Design（简称 AntD）是阿里巴巴团队开发的一套企业级 React UI 组件库，提供了丰富的高质量组件，遵循设计语言规范，帮助开发者快速构建美观的用户界面。

2. Ant Design 的设计理念 ​

设计原则说明
自然贴近现实，符合用户习惯
确定性界面清晰，反馈明确
意义功能与美感结合
生长性适应不同场景需求

3. Ant Design 的特点 ​

  • 开箱即用：提供丰富的组件，直接使用
  • 设计规范：统一的设计语言
  • 可定制性：支持主题定制
  • 国际化：多语言支持
  • 响应式：适配不同设备

import { Form, Input, Button, Select } from 'antd';
const { Option } = Select;

const DemoForm = () => {
  const [form] = Form.useForm();

  const onFinish = (values) => {
    console.log('表单值:', values);
  };

  const onFinishFailed = (errorInfo) => {
    console.log('表单验证失败:', errorInfo);
  };

  return (
    <Form
      form={form}
      name="basic"
      initialValues={{ remember: true }}
      onFinish={onFinish}
      onFinishFailed={onFinishFailed}
    >
      <Form.Item
        label="用户名"
        name="username"
        rules={[
          { required: true, message: '请输入用户名' },
          { min: 3, max: 10, message: '长度在3-10之间' },
        ]}
      >
        <Input placeholder="请输入用户名" />
      </Form.Item>

      <Form.Item
        label="密码"
        name="password"
        rules={[
          { required: true, message: '请输入密码' },
          { pattern: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[a-zA-Z\d]{8,}$/, message: '密码至少8位，包含大小写字母和数字' },
        ]}
      >
        <Input.Password placeholder="请输入密码" />
      </Form.Item>

      <Form.Item
        label="角色"
        name="role"
        rules={[{ required: true, message: '请选择角色' }]}
      >
        <Select placeholder="请选择角色">
          <Option value="admin">管理员</Option>
          <Option value="user">普通用户</Option>
          <Option value="guest">访客</Option>
        </Select>
      </Form.Item>

      <Form.Item>
        <Button type="primary" htmlType="submit">
          提交
        </Button>
      </Form.Item>
    </Form>
  );
};

3. Modal 弹窗组件 ​

jsx
import { Modal, Button } from 'antd';
import { useState } from 'react';

const ConfirmModal = () => {
  const [isModalVisible, setIsModalVisible] = useState(false);

  const showModal = () => {
    setIsModalVisible(true);
  };

  const handleOk = () => {
    setIsModalVisible(false);
    // 执行确认逻辑
  };

  const handleCancel = () => {
    setIsModalVisible(false);
  };

  return (
    <>
      <Button type="primary" onClick={showModal}>
        删除
      </Button>
      <Modal
        title="确认删除"
        visible={isModalVisible}
        onOk={handleOk}
        onCancel={handleCancel}
        okText="确认删除"
        cancelText="取消"
        okType="danger"
      >
        <p>确定要删除这条记录吗？此操作不可撤销。</p>
      </Modal>
    </>
  );
};

jsx

          fontSizeBase: '14px',
          
          // 间距
          spacingUnit: 8,
          paddingSM: 8,
          paddingMD: 16,
          
          // 圆角
          borderRadius: 4,
          borderRadiusSM: 2,
        },
        algorithm: theme.defaultAlgorithm, // 默认主题算法
      }}
    >
      <YourComponent />
    </ConfigProvider>
  );
};

1. Form 表单验证不生效 ​

问题：表单提交时验证规则没有触发。

原因及解决方案：

jsx
// 错误：没有给 Form.Item 设置 name 属性
<Form.Item label="用户名" rules={[{ required: true }]}>
  <Input />
</Form.Item>

// 正确：必须设置 name 属性
<Form.Item name="username" label="用户名" rules={[{ required: true }]}>
  <Input />
</Form.Item>

5. Ant Design 和原生 HTML 表单有什么区别？ ​

答：

  • 数据绑定：Ant Design Form 通过 form 对象进行数据管理
  • 验证机制：内置丰富的验证规则
  • 状态管理：自动管理表单状态（dirty、touched、error）
  • 易用性：提供表单联动、动态增减等高级功能

6. 如何处理表单联动？ ​

jsx
const DemoForm = () => {
  const [form] = Form.useForm();

  // 监听字段变化
  useEffect(() => {
    const unsubscribe = form.subscribe(
      (value) => {
        // 当 type 变化时重置其他字段
        if (value.type !== form.getFieldValue('type')) {
          form.setFieldsValue({ option: undefined });
        }
      },
      { fieldNames: ['type'] }
    );

    return unsubscribe;
  }, [form]);

  return (
    <Form form={form}>
      <Form.Item name="type">
        <Select placeholder="选择类型">...</Select>
      </Form.Item>
      <Form.Item name="option">
        <Select placeholder="选择选项">...</Select>
      </Form.Item>
    </Form>
  );
};

8. 如何在 Modal 中使用 Form？ ​

jsx
const ModalForm = () => {
  const [isVisible, setIsVisible] = useState(false);
  const [form] = Form.useForm();

  const handleOk = () => {
    form.validateFields().then((values) => {
      console.log(values);
      setIsVisible(false);
      form.resetFields();
    });
  };

  return (
    <>
      <Button onClick={() => setIsVisible(true)}>打开弹窗</Button>
      <Modal visible={isVisible} onOk={handleOk} onCancel={() => setIsVisible(false)}>
        <Form form={form} layout="vertical">
          <Form.Item name="name" rules={[{ required: true }]}>
            <Input placeholder="请输入名称" />
          </Form.Item>
        </Form>
      </Modal>
    </>
  );
};

八、总结 ​

Ant Design 是一套功能强大的 React UI 组件库，掌握其核心组件的使用方法和最佳实践对于前端开发至关重要。重点关注：

  1. Form 表单验证：规则配置、表单联动
  2. Table 数据展示：列配置、排序筛选、虚拟滚动
  3. Modal 弹窗交互：状态管理、表单集成
  4. 主题定制：ConfigProvider、Token 配置
  5. 性能优化：懒加载、React.memo

通过实践这些知识点，可以更好地应对 Ant Design 相关的面试问题。
