组件设计原则 ​

什么是好的组件设计？ ​

好的组件应该具备以下特征：

  • 可复用：可以在多个地方使用
  • 可维护：代码清晰，易于理解和修改
  • 可扩展：便于添加新功能
  • 可测试：独立的单元测试
  • 低耦合：减少对外部的依赖

组件设计原则 ​

1. 单一职责原则（SRP） ​

每个组件只做一件事。

vue
<!-- ❌ 不好的设计 - 职责过多 -->
<template>
  <div>
    <!-- 用户信息展示 -->
    <div class="user-info">...</div>
    
    <!-- 用户表单编辑 -->
    <form>...</form>
    
    <!-- 用户列表 -->
    <ul>...</ul>
    
    <!-- 搜索功能 -->
    <input type="search" />
  </div>
</template>

<!-- ✅ 好的设计 - 拆分成多个组件 -->
<UserProfile />
<UserForm />
<UserList />
<SearchBar />

UserProfile.logic.js：

javascript
import { ref, computed } from 'vue'
import { useUserStore } from '@/stores/user'

export function useUserProfile(userId) {
  const userStore = useUserStore()
  const loading = ref(false)
  const error = ref(null)
  
  const user = computed(() => 
    userStore.users.find(u => u.id === userId)
  )
  
  async function refresh() {
    loading.value = true
    try {
      await userStore.fetchUser(userId)
    } catch (err) {
      error.value = err.message
    } finally {
      loading.value = false
    }
  }
  
  return { user, loading, error, refresh }
}

function handleIncrement() {

2. 渲染函数组件 ​

javascript
// ErrorBoundary.js
import { defineComponent } from 'vue'

export default defineComponent({
  name: 'ErrorBoundary',
  data() {
    return {
      hasError: false,
      error: null
    }
  },
  errorCaptured(err, vm, info) {
    this.hasError = true
    this.error = err
    return false
  },
  render() {
    if (this.hasError) {
      return this.$slots.fallback 
        ? this.$slots.fallback({ error: this.error })
        : h('div', 'Something went wrong')
    }
    return this.$slots.default()
  }
})

2. 主题支持 ​

javascript
// composables/useTheme.js
import { ref, computed } from 'vue'

export function useTheme() {
  const theme = ref('light')
  
  const colors = computed(() => ({
    primary: theme.value === 'light' ? '#007bff' : '#0056b3',
    background: theme.value === 'light' ? '#ffffff' : '#1a1a1a',
    text: theme.value === 'light' ? '#333333' : '#ffffff'
  }))
  
  function toggleTheme() {
    theme.value = theme.value === 'light' ? 'dark' : 'light'
  }
  
  return { theme, colors, toggleTheme }
}

3. 无障碍支持 ​

vue
<!-- AccessibleButton.vue -->
<template>
  <button
    :aria-label="label"
    :aria-disabled="disabled"
    :tabindex="disabled ? -1 : 0"
    @keydown.enter="handleClick"
    @keydown.space.prevent="handleClick"

defineProps({
  label: { type: String, required: true },
  disabled: { type: Boolean, default: false }

function handleClick() {
  if (!props.disabled) {
    emit('click')
  }
}
</script>

vue
<script setup>

const error = ref(null)

onErrorCaptured((err, instance, info) => {
  error.value = err
  console.error('Component error:', err, info)
  return false // 阻止错误向上传播
})
</script>

<template>

总结 ​

优秀的组件设计要点：

✅ 单一职责 - 每个组件只做一件事 ✅ 组合优先 - 通过组合构建复杂 UI ✅ 清晰的接口 - Props 和 Events 定义明确 ✅ 灵活的插槽 - 提供足够的定制能力 ✅ 性能优化 - 避免不必要的渲染 ✅ 可测试性 - 独立的单元测试 ✅ 无障碍支持 - ARIA 属性、键盘导航 ✅ 文档完善 - 清晰的 API 文档

记住：好的组件设计 = 清晰的接口 + 灵活的可扩展性 + 良好的性能
