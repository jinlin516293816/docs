1. 响应式原理 ​

1.1 Proxy vs Object.defineProperty ​

问题：Vue 3 为什么选择 Proxy 而不是 Object.defineProperty？

答案：

  • Proxy 可以直接监听对象和数组的变化，不需要遍历对象属性
  • Proxy 可以监听新增和删除属性，而 Object.defineProperty 只能监听已有属性
  • Proxy 性能更好，因为它是浏览器原生支持的
  • Proxy 返回的是新对象，可以直接操作新对象，而 Object.defineProperty 需要修改原对象
javascript
// Vue 2 使用 Object.defineProperty
Object.defineProperty(obj, 'key', {
  get() { /* 依赖收集 */ },
  set() { /* 触发更新 */ }
});

// Vue 3 使用 Proxy
new Proxy(obj, {
  get(target, key) { /* 依赖收集 */ },
  set(target, key, value) { /* 触发更新 */ }
});

1.2 依赖收集与触发更新 ​

问题：Vue 的响应式系统是如何实现依赖收集和触发更新的？

答案：

  1. 依赖收集阶段：当组件渲染时，会读取响应式数据，触发 Proxy 的 get 陷阱
  2. 收集依赖：在 get 陷阱中将当前的 effect 函数（渲染函数或 watch 回调）收集到依赖集合中
  3. 触发更新阶段：当响应式数据被修改时，触发 Proxy 的 set 陷阱
  4. 执行依赖：遍历依赖集合，执行所有相关的 effect 函数
javascript
// 简化版依赖收集
class Dep {
  constructor() {
    this.subscribers = new Set();
  }
  
  depend() {
    if (activeEffect) {
      this.subscribers.add(activeEffect);
    }
  }
  
  notify() {
    this.subscribers.forEach(effect => effect());
  }
}

2. 虚拟 DOM ​

2.1 虚拟 DOM 的作用 ​

问题：为什么需要虚拟 DOM？

答案：

  • 减少直接操作 DOM：DOM 操作是昂贵的，虚拟 DOM 可以批量更新
  • 跨平台：虚拟 DOM 可以渲染到不同平台（浏览器、SSR、小程序等）
  • diff 算法优化：通过 diff 算法最小化 DOM 操作

2.2 Diff 算法 ​

问题：Vue 的 diff 算法是如何工作的？

答案：

  1. 同层比较：只比较同一层级的节点
  2. key 的作用：通过 key 快速找到可复用的节点
  3. 双端比较：从两端向中间比较，减少比较次数
  4. 最长递增子序列：优化列表排序时的 DOM 操作

核心原则：

  • 只比较同层级节点
  • 先比较 key，再比较类型
  • 尽量复用节点，减少 DOM 操作

3. 编译过程 ​

3.1 模板编译 ​

问题：Vue 的模板是如何编译成渲染函数的？

答案：

  1. 解析阶段：将模板字符串解析成 AST（抽象语法树）
  2. 优化阶段：标记静态节点，优化 diff 过程
  3. 生成阶段：将 AST 转换为渲染函数
javascript
// 模板
<div>{{ message }}</div>

// 编译后的渲染函数
function render() {
  return _createElement('div', null, [_toString(_ctx.message)]);
}

3.2 静态提升 ​

问题：什么是静态提升？为什么需要它？

答案：

  • 静态提升：将静态节点提取到渲染函数外部，避免每次渲染都重新创建
  • 好处：减少内存占用，提高渲染性能
javascript
// 未优化
function render() {
  return _createElement('div', null, ['Hello']);
}

// 优化后
const staticText = 'Hello';
function render() {
  return _createElement('div', null, [staticText]);
}

4. 组件化机制 ​

4.1 组件实例创建过程 ​

问题：Vue 组件实例是如何创建的？

答案：

  1. 创建 VNode：解析组件定义，创建虚拟节点
  2. 实例化：创建组件实例，初始化生命周期
  3. 挂载：调用 render 函数，生成 DOM 并挂载

4.2 组件通信 ​

问题：Vue 组件间通信有哪些方式？

答案：

  • props / emit：父子组件通信
  • provide / inject：跨层级组件通信
  • eventBus：全局事件总线
  • Vuex / Pinia：状态管理
  • $parent / $children：直接访问组件实例

5. 生命周期 ​

5.1 生命周期钩子执行顺序 ​

问题：Vue 组件的生命周期钩子执行顺序是怎样的？

答案：

  1. beforeCreate：实例创建前，无法访问 data 和 methods
  2. created：实例创建完成，可以访问 data 和 methods
  3. beforeMount：挂载前，模板已编译但未挂载到 DOM
  4. mounted：挂载完成，DOM 已更新
  5. beforeUpdate：更新前，响应式数据已更新但 DOM 未更新
  6. updated：更新完成，DOM 已更新
  7. beforeUnmount：卸载前
  8. unmounted：卸载完成

5.2 keep-alive 的作用 ​

问题：keep-alive 是如何实现组件缓存的？

答案：

  • 缓存机制：将组件实例缓存到内存中，避免重复创建
  • include / exclude：通过正则表达式匹配组件名称
  • max：限制缓存组件数量

6.2 computed 的实现原理 ​

问题：computed 是如何实现懒计算和缓存的？

答案：

  • 懒计算：只有在访问时才会计算
  • 缓存机制：依赖不变时，返回缓存结果
  • 依赖追踪：自动追踪响应式依赖
javascript
const doubled = computed(() => count.value * 2);
// 只有访问 doubled.value 时才会计算

7. 编译器优化 ​

7.1 PatchFlags ​

问题：Vue 3 的 PatchFlags 是什么？

答案：

  • 优化标记：编译时给 VNode 添加标记，标识需要更新的内容
  • 类型：TEXT、CLASS、STYLE、PROPS、FULL_PROPS、HYDRATE_EVENTS 等
  • 作用：在 diff 过程中快速判断是否需要更新

7.2 静态节点标记 ​

问题：静态节点是如何被标记和优化的？

答案：

  • 静态提升：将静态节点提取到渲染函数外部
  • 静态标记：标记纯静态节点，跳过 diff 比较
  • 静态树提升：将整个静态子树提升

8. 性能优化 ​

8.1 Vue 的性能优化策略 ​

问题：Vue 内部有哪些性能优化策略？

答案：

  1. 响应式优化：Proxy 替代 Object.defineProperty
  2. 编译优化：静态提升、PatchFlags
  3. diff 优化：双端比较、最长递增子序列
  4. 渲染优化：Fragment、Suspense

8.2 如何优化大型列表渲染 ​

问题：如何优化大型列表的渲染性能？

答案：

  • 虚拟滚动：只渲染可见区域
  • 列表复用：使用 key 复用 DOM 节点
  • 分片渲染：将列表分成多个片段，分批渲染

9. 面试常问 ​

9.1 Vue 3 比 Vue 2 好在哪里？ ​

答案：

  • 性能更好：Proxy 响应式、编译优化
  • Composition API：更灵活的代码组织
  • TypeScript 支持：更好的类型推断
  • 更小的体积：按需引入

9.2 为什么 Vue 3 使用 Composition API？ ​

答案：

  • 逻辑复用：更容易提取和复用组件逻辑
  • 类型推断：更好的 TypeScript 支持
  • 代码组织：按功能组织代码，而非选项
  • 更好的 tree-shaking：只打包使用的功能

9.3 Vue 和 React 的区别？ ​

答案：

特性VueReact

响应式自动响应式手动 setState
状态管理Vuex/PiniaRedux/Zustand
学习曲线较低较高

10. 总结 ​

Vue 源码的核心要点：

  1. 响应式系统：Proxy + 依赖收集
  2. 虚拟 DOM：diff 算法优化
  3. 编译过程：模板到渲染函数
  4. 组件化：实例创建与生命周期
  5. 性能优化：编译优化、运行时优化

理解这些核心概念，能够更好地使用 Vue 并解决实际问题。
