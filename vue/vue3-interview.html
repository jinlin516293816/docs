Vue 3 面试题 ​

一、响应式原理 ​

1. Vue 3 响应式系统的核心是什么？ ​

答案：Vue 3 使用 Proxy 实现响应式系统。通过 Proxy 代理对象，在属性访问时收集依赖，在属性修改时触发更新。

javascript
const proxy = new Proxy(target, {
  get(target, key, receiver) {
    track(target, key); // 依赖收集
    return Reflect.get(target, key, receiver);
  },
  set(target, key, value, receiver) {
    const result = Reflect.set(target, key, value, receiver);
    trigger(target, key); // 触发更新
    return result;
  }
});

2. Proxy 相比 Object.defineProperty 有什么优势？ ​

答案：

  • 可以监听对象属性的新增和删除
  • 可以监听数组的变化
  • 性能更好，是浏览器原生支持
  • 无需遍历对象属性

4. computed 的实现原理？ ​

答案：computed 是一个惰性求值的响应式依赖，只有在访问时才会计算，并且会缓存结果。当依赖变化时，会标记为脏数据，下次访问时重新计算。

二、组合式 API ​

5. Composition API 和 Options API 的区别？ ​

答案：

  • 代码组织：Composition API 按功能组织代码，Options API 按选项组织
  • 逻辑复用：Composition API 更容易复用逻辑
  • 类型推断：Composition API 更好的 TypeScript 支持
  • 灵活性：Composition API 更灵活

6. setup 函数的执行时机？ ​

答案：setup 在组件实例创建之前执行，此时无法访问 this。它接收 props 和 context 两个参数。

7. watch 和 watchEffect 的区别？ ​

答案：

  • watch：需要明确指定监听的数据源
  • watchEffect：自动追踪所有响应式依赖
  • 执行时机：watch 默认懒执行，watchEffect 立即执行
javascript
// watch
watch(() => state.count, (newVal, oldVal) => {
  console.log(newVal, oldVal);
});

// watchEffect
watchEffect(() => {
  console.log(state.count);
});

三、虚拟 DOM 与 Diff ​

8. Vue 3 的 Diff 算法有什么优化？ ​

答案：

  • 静态提升：将静态节点提取到渲染函数外部
  • PatchFlags：编译时标记节点的更新类型
  • 最长递增子序列：优化列表排序

9. key 的作用是什么？ ​

答案：key 用于在 diff 过程中识别节点，帮助 Vue 快速找到可复用的 DOM 节点，提高渲染性能。

四、生命周期 ​

10. Vue 3 的生命周期钩子有哪些？ ​

答案：

  • setup() - 创建前
  • onBeforeMount() - 挂载前
  • onMounted() - 挂载后
  • onBeforeUpdate() - 更新前
  • onUpdated() - 更新后
  • onBeforeUnmount() - 卸载前
  • onUnmounted() - 卸载后
  • onErrorCaptured() - 错误捕获

11. keep-alive 的作用？ ​

答案：keep-alive 用于缓存组件实例，避免重复创建和销毁，提高性能。

五、组件通信 ​

12. Vue 3 中有哪些组件通信方式？ ​

答案：

  • props / emit：父子组件通信
  • provide / inject：跨层级通信
  • eventBus：事件总线
  • Pinia：状态管理
  • $parent / $children：直接访问

13. provide / inject 如何实现响应式？ ​

答案：传递响应式对象或使用 ref/reactive，确保子组件能响应数据变化。

六、性能优化 ​

14. Vue 3 有哪些性能优化策略？ ​

答案：

  • 编译优化：静态提升、PatchFlags
  • 响应式优化：Proxy 替代 Object.defineProperty
  • 渲染优化：Fragment、Suspense
  • 运行时优化：缓存、懒加载

15. 如何优化大型列表？ ​

答案：

  • 虚拟滚动：只渲染可见区域
  • 无限滚动：分批加载数据
  • 列表复用：使用 key 复用 DOM 节点

七、其他 ​

16. Vue 3 为什么移除过滤器？ ​

答案：过滤器可以用计算属性或方法替代，更灵活且易于理解。

17. Teleport 的作用？ ​

答案：Teleport 可以将组件渲染到 DOM 的其他位置，用于模态框等场景。

18. Suspense 是什么？ ​

答案：Suspense 用于处理异步组件的加载状态，提供 loading 状态和错误处理。

八、高频面试题 ​

19. 请实现一个简单的响应式系统？ ​

答案：

javascript
const targetMap = new WeakMap();

function track(target, key) {
  let depsMap = targetMap.get(target);
  if (!depsMap) {
    depsMap = new Map();
    targetMap.set(target, depsMap);
  }
  let deps = depsMap.get(key);
  if (!deps) {
    deps = new Set();
    depsMap.set(key, deps);
  }
  if (activeEffect) {
    deps.add(activeEffect);
  }
}

function trigger(target, key) {
  const depsMap = targetMap.get(target);
  if (!depsMap) return;
  const deps = depsMap.get(key);
  if (deps) {
    deps.forEach(effect => effect());
  }
}

let activeEffect = null;
function effect(fn) {
  activeEffect = fn;
  fn();
  activeEffect = null;
}

20. Vue 3 和 Vue 2 的区别？ ​

答案：

  • 响应式系统：Proxy vs Object.defineProperty
  • API：Composition API vs Options API
  • 性能：编译优化、运行时优化
  • 体积：更小的打包体积
  • TypeScript：更好的类型支持

总结 ​

Vue 3 的核心改进包括：

  1. 响应式系统：使用 Proxy 实现
  2. Composition API：更灵活的代码组织
  3. 性能优化：编译时优化和运行时优化
  4. TypeScript 支持：更好的类型推断
